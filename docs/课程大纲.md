# 《遥感软件设计与开发综合实习》课程教学大纲

## 一、 课程简介与总体目标
本实践课程旨在帮助学生完成从“理论理解”到“代码实现”，再到“工程化系统构建”的跨越。在先修《遥感图像处理》、《计算机程序设计》、《数据结构》等课程的基础上，实现以下三大目标：
1. **算法落地**：脱离现有商业软件（如ENVI/ERDAS），使用程序语言从底层实现遥感图像的核心处理算法。
2. **工程思维**：掌握代码版本控制、UI界面开发、多线程调度与日志系统，具备真实的软件工程化开发思维。
3. **团队协作**：通过小组合作形式，以具体行业应用为背景，完成一个完整的遥感应用系统软件。

## 二、 核心技术栈与工程规范
*教学设计：允许各小组根据自身编程基础和未来求职规划，在 Python 或 C++ 中任选一种作为开发语言。*

| 技术维度 | 🐍 Python 开发轨 (推荐/效率优先) | ⚙️ C++ 开发轨 (进阶/性能与底层优先) |
| :--- | :--- | :--- |
| **构建与环境** | Anaconda, pip | CMake, vcpkg / Visual Studio .sln |
| **底层与空间库** | GDAL, Rasterio, PyProj | GDAL C++ API, OSR |
| **矩阵与运算** | NumPy (矩阵广播与并行计算) | Eigen, 裸指针/一维数组 (注意行列遍历内存命中) |
| **GUI 界面库** | PyQt5 / PySide6 | 原生 Qt5 / Qt6 |
| **机器学习库** | Scikit-learn / PyTorch | OpenCV (`cv::ml` 模块) |
| **打包与部署** | PyInstaller (打包为单一.exe) | windeployqt + 动态链接库(DLL)提取 |

* **协作与工程规范（重点要求）**：
  * Git 版本控制（GitHub / Gitee平台协同开发）。
  * 日志系统（Logging）替代 `print()`，以及完整的 Try-Catch 异常处理机制。
  * 规范化的代码注释（Docstrings）。

## 三、 教学实施模式：“1+1+N”闯关开发机制
为了兼顾知识的系统性与学生个体的兴趣差异，实践内容采用**“菜单式”**开发模式：
* **“1”个共同底座（必做）**：所有小组必须完成环境搭建、影像与矢量底层读写，搭建起带基础UI的软件框架。
* **“1”套基础算法（必做）**：掌握基础图像增强、滤波与基础特征计算（如NDVI），夯实基本功。
* **“N”个特色模块（选做）**：各小组根据自己选择的【最终应用系统选题】，有侧重地选择**辐射校正**、**图像匹配**或**机器学习分类**等高阶算法进行深度的代码级开发。

## 四、 课程核心内容模块划分

### 模块一：底层数据读写与系统框架搭建（基础必做篇）
*目标：掌握空间数据结构，建立带基础交互界面的软件底座。*
* **1.1 开发环境与工程协作准备**
  * 开发环境配置与依赖包管理（Anaconda等）。
  * Git团队协作实战（Clone, Commit, Branch, 合并冲突解决）。
* **1.2 多源空间数据底层I/O操作**
  * **栅格处理**：基于GDAL获取GeoTIFF元数据（行列数、波段数、投影信息）。
  * **内存管理差异**：Python组掌握分块读写（Block）；**[C++重点]** 掌握 GDAL 指针的正确释放（`GDALClose`）与内存泄漏防范。
  * **矢量交互（痛点解决）**：Shapefile/GeoJSON边界读取，及**基于矢量多边形的遥感影像掩膜裁剪（Mask/Clip）**代码实现。
  * **性能优化**：影像分块（Block）读写技术与**影像金字塔（Pyramids）**构建，解决超大影像内存溢出与渲染卡顿问题。
* **1.3 影像可视化与UI前端搭建**
  * 编写代码实现灰度显示、真彩色与标准假彩色合成（含影像金字塔的初步应用）。
  * 界面库（PyQt）基础：搭建主界面（菜单栏、工具栏、图层树管理、视图区）。

### 模块二：核心预处理算法代码实现（进阶选做篇）
*目标：脱离调包，纯代码编写遥感预处理的核心数学与逻辑算法。*
* **2.1 辐射增强与空间滤波（必做基础）**
  * 图像线性拉伸算法（如2%截断拉伸）与直方图均衡化（全局/局部）。
  * 植被指数（NDVI等）与水体指数的NumPy矩阵并行计算程序。
  * 空间滤波：均值、高斯滤波卷积核实现；边缘检测（Sobel算子）。
* **2.2 辐射定标与大气校正（定量遥感方向·选做）**
  * **辐射定标**：读取Metadata提取增益/偏移量，实现DN值到辐射亮度（Radiance）或表观反射率（TOA）的转换。
  * **大气校正**：编程实现简易暗目标法（DOS），消除程辐射影响，获取地表真实反射率。
* **2.3 几何校正与图像匹配（摄影测量与CV方向·选做）**
  * **坐标与投影（痛点解决）**：利用代码（如pyproj或GDAL OSR）实现坐标参考系统（CRS）解析与动态投影转换。
  * **图像匹配**：手写NCC模板匹配；或调用OpenCV实现SIFT/ORB特征点提取与同名点匹配。
  * **自动配准**：利用匹配同名点，自动计算仿射变换或单应性矩阵（Homography），实现两期影像自动配准及重采样。

### 模块三：高级信息提取与分类（高阶选做篇）
*目标：掌握遥感影像自动解译与特征提取的算法流程。*
* **3.1 传统机器学习分类（分类与提取方向·选做）**
  * K-Means非监督分类算法的纯代码实现。
  * 随机森林（RF）或支持向量机（SVM）监督分类流程封装。
  * 分类精度评价模块编写（混淆矩阵、总体精度、Kappa系数）。
* **3.2 数据降维与深度学习（探索进阶·选做）**
  * 主成分分析（PCA）算法的协方差矩阵求解与特征空间变换代码实现。
  * 基于预训练模型（如U-Net）的建筑物/道路语义分割简单推断应用。

### 模块四：遥感应用系统集成与开发（实战综合篇）
*目标：引入真实软件工程规范，将算法整合为健壮的应用系统。*
* **4.1 UI前端与算法后端的信号绑定**
  * 基于 Qt 信号与槽机制，将界面按钮与底层的核心算法打通。
* **4.2 工业级系统鲁棒性提升（核心痛点修复）**
  * **防界面假死**：引入 `QThread`，将耗时的遥感算法放入后台线程运行。
  * **防崩溃闪退**：
    * Python组：引入 `try...except` 拦截异常，使用 `logging` 模块记录运行日志。
    * C++组：重点进行内存泄漏检测，使用智能指针替换裸指针，防止 GDI 句柄耗尽或越界段错误。
* **4.3 系统打包与发版**
  * Python组使用 PyInstaller；C++组使用 Qt 部署工具及 DLL 依赖打包，最终输出可独立在纯净电脑上双击运行的软件压缩包。

### 模块五：成果展示与答辩（总结考核篇）
* **5.1 系统演示**：各小组现场运行并演示自己开发的系统业务流。
* **5.2 代码抽查**：针对小组负责的核心算法进行提问，检验独立完成度与底层逻辑理解。
* **5.3 答辩汇报**：分享系统架构设计、遇到的技术难点及解决方案。

## 六、 小组项目（System）选题库建议
*各小组可从中任选其一，或自拟具有同等工作量的题目。每个系统必须包含UI界面和完整的业务逻辑流。*

1. **定量遥感参数反演平台**（侧重模块2.2）：实现“DN值 -> 辐射亮度 -> 地表反射率”流水线；结合经验公式进行地表温度(LST)、叶面积指数(LAI)定量计算与制图。
2. **多源多时相变化检测分析仪**（侧重模块2.3）：利用图像匹配自动配准两期影像；解决投影冲突；利用辐射校正消除传感器差异；计算差值提取并标红违建或森林砍伐区域。
3. **无人机影像拼接与配准工具**（侧重模块2.3）：提取相邻影像同名特征点，计算单应性矩阵；实现多幅影像重采样拼接与接缝线消除，输出大画幅全景图。
4. **农业灾害智能评估系统**（侧重模块3.1/1.2）：导入矢量田块边界裁剪影像（Mask）；进行农作物监督分类（SVM/RF）；自动计算区域干旱指数/植被覆盖度。
5. **轻量级遥感图像处理平台（Mini-ENVI）**（侧重模块1.3/2.1）：构建健壮的图像金字塔文件树管理；开发丰富的拉伸增强显示、多种滤波算法、影像裁剪与波段组合功能。

## 八、 教学实施小贴士（Teacher's Tips）
1. 提供脚手架代码（Boilerplate）：建议在第一周由老师提供一个带基础菜单栏和空白图像画布的框架代码。这可以避免学生在界面调整上浪费过多时间，从而聚焦于“遥感算法实现”。
2. 测试数据准备：教师应提前准备好标准化的测试数据集（如Landsat 8、Sentinel-2或无人机样例影像），并包含对应的Metadata头文件，以保证辐射定标和匹配算法能够顺利读取所需参数。
3. 性能优化指导：在涉及到如直方图均衡化、空间滤波的全局运算时，鼓励学生使用NumPy的矩阵广播机制或并行计算，代替缓慢的双重for循环嵌套计算像元，这也是极其重要的编程实践经验。
